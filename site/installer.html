Installer l'appli

Deux clés, ton adresse, un bouton. Environ 5 minutes, 10 si tu crées tes comptes.

Tes deux comptes

Gratuits, à faire une seule fois. Déjà faits ? Passe à l'étape 1.

Créer mon compte GitHub 3 min

GitHub garde le code de ton appli et la met en ligne.

  1. Ouvre github.com/signup
  2. Ton e-mail (celui du travail convient), puis un mot de passe.15 caractères, ou 8 avec au moins un chiffre et une minuscule.
  3. Un nom d'utilisateur. Il sera dans l'adresse de ton appli : https://ton-nom.github.io/plan-de-com/Simple, en minuscules, avec des tirets si besoin. Exemple : com-executive
  4. Pays : France. Puis le bouton Continue ou Create account.
  5. GitHub vérifie que tu n'es pas un robot : Verify, puis suis le petit jeu d'images.
  6. Un code à 8 chiffres arrive par e-mail : tape-le.Rien reçu ? Regarde dans les indésirables.
  7. Connecte-toi. Si GitHub pose des questions (équipe, centres d'intérêt), tout en bas : Skip personalization.

C'est prêt. Note ton nom d'utilisateur et ton mot de passe.

Plus tard, GitHub peut te demander un code sur ton téléphone à la connexion. Suis ses écrans : l'appli n'est pas concernée.

Créer mon compte Supabase 2 min

Supabase garde les données de ton appli : actions, comptes, réglages. Ton compte GitHub suffit pour y entrer.

  1. Ouvre supabase.com/dashboard/sign-up
  2. Le bouton Continue with GitHub, puis, sur la page de GitHub, le bouton vert Authorize supabase.Pas de nouveau mot de passe à inventer.
  3. Supabase te demande une organisation. Name : ton équipe. Plan : Free, 0 $. Puis Create organization.
  4. Supabase propose ensuite Create a new project : ne le fais pas, l'installateur s'en charge.

C'est prêt. Passe à l'étape 1.

Un compte gratuit a droit à 2 bases. Si tu en as déjà 2, mets-en une en pause sur supabase.com avant d'installer.
