Tu continues à travailler dans ton outil. Le plan de com suit tout seul, et l'inverse aussi.

Ton Asana ou ton Trello
J'utilise

Relier, une seule fois

Dans l'appli plan de com, sur ordinateur.

1

Ouvre ton profil

Réglages›Mon profil›Mon Asana, mon Trello›Relier
2

Crée ta clé Asana

  1. Clique sur Créer une clé Asana. La page des clés d'Asana s'ouvre.
  2. + Create new token, nomme-la Plan de com, accepte les conditions, puis Create token.
  3. Copie la clé et colle-la dans l'appli, puis Suivant.
2

Crée ta clé et ton jeton Trello

  1. Clique sur Ma clé Trello. Sur la page de Trello : New, nomme-le Plan de com, choisis ton espace de travail, puis Create.
  2. Generate a new API key, copie la clé (API key) et colle-la dans la case Clé.
  3. Le lien Mon jeton apparaît : clique, puis Autoriser chez Trello. Copie le jeton dans la case Jeton, puis Suivant.
3

Choisis ton projetChoisis ta liste

C'est là qu'arrivent les actions que tu envoies. C'est aussi le projetSon tableau est aussi celui où l'étiquette « Plan de com » fonctionne.

4

C'est relié

La coche verte et la pastille Plan de com le confirment.

Au quotidien

Deux gestes, selon l'endroit où naît l'action.

Du plan vers  Asana Trello

Sur la fiche d'une action, clique sur les deux flèches . La tâcheLa carte est créée chez toi. Les flèches passent au vert.

D'AsanaDe Trello vers le plan

  1. Sur une tâche du projet relié : ⋯›Ajouter des tags, tape Plan de com, puis Entrée.
  2. Sur une carte du tableau relié : Étiquettes›Créer une nouvelle étiquette, nomme-la Plan de com. Ensuite, coche-la simplement sur les autres cartes.
  3. L'action arrive dans le plan, À confirmer, dans ton service, à la date d'échéance. Tout le monde voit qu'elle vient de chez toi.

Questions

Faut-il un abonnement payant ?

Non. La version gratuite d'Asana et celle de Trello suffisent.

Qui voit ma clé ?

Personne, même pas toi après l'avoir collée. Elle reste dans la base, seule la synchronisation s'en sert.

Je mets l'étiquette, rien n'arrive.

Vérifie que la tâche est dans le projetla carte est dans le tableau choisi à l'étape 3. Ailleurs, l'étiquette n'a pas d'effet. Ouvre aussi Réglages › Mon profil : la pastille « Plan de com » doit être là.

Changer de projetliste ou arrêter ?

Réglages › Mon profil : le crayon pour changer, la corbeille pour délier. Ce qui est déjà chez toi y reste.

J'ai Asana et Trello.

Tu peux relier les deux. Sur une fiche, les deux flèches proposent alors l'un ou l'autre.

Une question ? Demande à la personne qui pilote le plan de com.
