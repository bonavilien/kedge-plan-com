SupabaseGitHub6 min

  1. Project Settings›API Keys
  2. L’adresse du projet, du genre https://abcdefgh.supabase.co (dans Data API si elle n’est pas là).
  3. La clé publishable, qui commence par sb_publishable_ (à défaut, la clé anon).

Installer le bouton Mettre à jour

GitHubSupabase5 minune seule fois

a. Une clé GitHub, limitée à ta copie

  1. ta photo›Settings›Developer settings›Personal access tokens›Fine-grained tokens›Generate new token
  2. Nom : Plan de com mise à jour Expiration : la plus longue (note la date, il faudra la refaire).
  3. Repository access›Only select repositories ta copie seulement.
  4. Permissions›Repository permissions en Read and write : Contents Workflows Actions
  5. Generate token puis copie la clé, qui commence par github_pat_. Elle ne s’affiche qu’une fois.

b. La ranger dans Supabase

  1. Edge Functions›Secrets
GITHUB_TOKENla clé GitHub
GITHUB_REPOton-compte/plan-de-com

c. Installer le bouton

  1. Ouvre index.ts et copie-le avec Copy raw file
  2. Edge Functions›Deploy a new function›Via Editor
  3. Nom : mise-a-jour Remplace tout le contenu par ce que tu as copié, puis Deploy function
  4. Details désactive Verify JWT et enregistre.
  5. Dans ton appli : Réglages›Version

À jour

Ensuite, au quotidien

Une nouvelle version sort : un pilote ouvre Réglages›Version›Mettre à jour

  1. Baseta base change, tes données restent
  2. Codeta copie récupère le nouveau code
  3. En lignel’appli se recharge seule, en une à trois minutes

Seuls les pilotes voient le bouton. Les autres reçoivent la nouvelle version au rechargement suivant.

Si quelque chose coince

« Le bouton n’est pas encore installé »

Étape 6, c. Vérifie que la fonction s’appelle bien mise-a-jour.

« GitHub refuse le jeton »

La clé GitHub a expiré : refais l’étape 6, a, puis remplace GITHUB_TOKEN.

« GitHub refuse l’accès »

GITHUB_REPO est mal écrit, ou une permission manque à la clé (Contents, Workflows, Actions).

« Ta copie a été modifiée à la main »

Dans ta copie sur GitHub : Sync fork›Discard commits Tes variables ne bougent pas.

« Le script 00xx n’est pas passé »

Rien n’a été changé par ce script et le code n’a pas été mis à jour. Envoie le message à l’auteur de l’appli.

« La publication échoue dans Actions »

Il manque KPLAN_SUPABASE_URL ou KPLAN_SUPABASE_KEY, ou c’est la clé secrète au lieu de la publishable.

Bon à savoir

  • Notifications sur téléphoneFacultatives, elles demandent une étape technique en plus. Sans elles, l’appli marche entièrement.
  • Pas de retour arrière automatiqueUne mise à jour de la base ne se défait pas d’un clic. Elle est prévue pour garder toutes les données.
  • Le bouton lui-mêmeIl change rarement. Quand c’est le cas, Réglages, Version le signale : recolle la fonction (étape 6, c).
